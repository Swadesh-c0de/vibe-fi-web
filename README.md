# Vibe-Fi Website

**Repository:** [Swadesh-c0de/vibe-fi-go](https://github.com/Swadesh-c0de/vibe-fi-go)

A high‑performance product landing page and documentation portal for **Vibe‑Fi (Go Edition)** – a fast, zero‑config terminal music player for Linux & macOS built with Go and Bubble Tea.

## Features

- Gruvbox Material aesthetic with custom Vibe‑Fi branding.
- Light/Dark mode switcher with persistence.
- Terminal player showcase (video demo, audio visualizers, YouTube streaming, synchronized lyrics).
- Multi‑route documentation portal:
  - `/docs` – overview & architecture.
  - `/docs/installation` – multi‑platform guide.
  - `/docs/usage` – CLI flags, streaming, playlists, Waybar integration.
  - `/docs/hotkeys` – shortcut cheatsheet.
- 100 % Vibe‑Fi focused content.
- Ready for static export on Vercel, Netlify, Cloudflare Pages, GitHub Pages.

## Deployment

- **Vercel** – import the repository on [Vercel](https://vercel.com) and use the default settings. Live site: https://vibe-fi.vercel.app.

- Netlify / Cloudflare Pages – set the build command to `npm run build` and the publish directory to `out`.
